# AI NAVI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** לבנות אפליקציית ווב מלאה בעברית המשלבת מצגת אינטראקטיבית בת 26 שקופיות, שאלון ניווט, מנוע המלצות מבוסס חוקים ותוצאה מודפסת עם מסלול עבודה.

**Architecture:** תת־פרויקט Vite/React/TypeScript מבודד ב־`ai-navi/`, עם תוכן ונתונים מקומיים, לוגיקת תחום טהורה שאינה תלויה ב־React, ומעטפות UI נפרדות למצגת, לנווט ולתוצאה. Zustand אינו נדרש; מצב חוצה מסכים נשמר בשכבת אחסון קטנה מעל `localStorage` ומועבר דרך React Context.

**Tech Stack:** Vite 7, React 19, TypeScript 5, React Router 7, Tailwind CSS 4, Framer Motion 12, Lucide React, Vitest, Testing Library.

## Global Constraints

- תמיכה מלאה בעברית וב־RTL.
- 26 שקופיות עם הערות מנחה, זמן מומלץ ואינטראקציות.
- לפחות 12 מסלולים מוכנים ותשע משפחות כלים.
- אין API חיצוני, התחברות או בסיס נתונים בגרסה הראשונה.
- אין מחירים מדויקים או הבטחות אבטחה; לכל כלי יש `lastReviewed`.
- תוצאה כוללת מסלול, 2–4 כלים, הסבר, חלופה, פרומפט ואזהרה.
- ניווט מקלדת, focus גלוי, reduced motion, Responsive והדפסה.
- דוגמאות ותוכן כוללים חינוך, ניהול, יזמות, שיווק ושימוש כללי.
