# AI NAVI

AI NAVI הוא מוצר React בעברית ובכיוון RTL לבחירת דרך עבודה עם כלי בינה מלאכותית. הוא מתחיל במשימה ובתוצר הרצוי, ולא בשם של כלי, ומשרת הקשרים של חינוך, ניהול, יזמות, שיווק ושימוש כללי.

## דרישות והפעלה מקומית

נדרש Node.js 20 ומעלה ו־npm.

```bash
npm install
npm run dev
```

פקודות זמינות:

```bash
npm run dev       # שרת פיתוח
npm run build     # בדיקת TypeScript ובניית production
npm run preview   # תצוגה מקדימה של build מקומי
npm run test      # כל בדיקות Vitest
npm run typecheck # בדיקת טיפוסים בלבד
```

## מסכים ונתיבים

- `/` — שער כניסה והסבר על שיטת הניווט.
- `/navigator` — שאלון אישי בן שבעה צעדים, כולל שער פרטיות.
- `/results` — מסלול מומלץ, חלופות, אחריות אנושית, פרומפט והדפסה. טעינה ישירה ללא מצב מלא מפנה להשלמת הניווט.
- `/presentation` — מצגת אינטראקטיבית עם תצוגת מרצה ומשחקים מקומיים.

## מפת התוכן

- `src/data/families.ts` — תשע משפחות כלי AI.
- `src/data/tools.ts` — קטלוג כלים, רמת פרטיות ותאריך בדיקה אחרון.
- `src/data/routes.ts` — מסלולים מוכנים ושלבי עבודה.
- `src/data/tasks.ts` — דוגמאות משימה שמופיעות במוצר; זה הקובץ לערוך או לעדכן כשמוסיפים דוגמאות לקהלים ולהקשרים שונים, גם ללא שינוי בקוד הממשק.
- `src/data/questions.ts` — שאלות ואפשרויות ה־Navigator.
- `src/data/slides.ts` — תוכן המצגת והערות המרצה.
- `src/lib/recommendationEngine.ts` — התאמת מסלול, סינון ודירוג בטוח.
- `src/styles/print.css` — חוזה ההדפסה של מסך התוצאות.

תאריכי `lastReviewed` מתארים מתי רשומת כלי נבדקה לאחרונה. הם אינם הבטחה למחיר, זמינות או יכולת עדכנית; יש לבדוק מידע רלוונטי לפני החלטה.

בעת עריכת תוכן השתמשו בניסוח זהיר כגון "עשוי לסייע". אין להבטיח תוצאה, דיוק, זמינות, מחיר או התאמה מוחלטת; יש להשאיר בדיקה והחלטה בידי אדם.

## קיצורי מקלדת במצגת

- `→` או `↓` — השקופית הבאה; `←` או `↑` — הקודמת.
- `Space` או `Enter` — חשיפת התוכן הבא, ואז מעבר קדימה.
- `Home` / `End` — התחלה / סוף.
- `N` — פתיחה או סגירה של הערות מרצה.
- `F` — בקשת מסך מלא.
- `Esc` — סגירת הערות המרצה.

קיצורי המצגת אינם משתלטים על מקשים כאשר המיקוד נמצא בשדה, קישור, כפתור או פקד אינטראקטיבי.

## פרטיות ואחריות

ההמלצות מסייעות בבחירה ואינן תחליף לשיקול דעת מקצועי. AI NAVI אינו ייעוץ משפטי ואינו ייעוץ באבטחת מידע. אין להעלות מידע אישי, סודי או ארגוני לכלי ציבורי ללא הרשאה. מדיניות הארגון היא הקובעת, ובכל תוצר יש לבדוק דיוק, מקורות, זכויות, התאמה לקהל ואיכות בעברית. בחירות במשחקי המצגת נשמרות מקומית במסך בלבד ואינן נשלחות לשירות חיצוני.

מצב הניווט נשמר ב־`localStorage` תחת מפתחות ממוספרי גרסה כדי לאפשר חזרה בטוחה. פעולת "ניווט חדש" מוחקת רק את מצב ה־Navigator לאחר אישור.

## הדפסה ושמירה כ־PDF

במסך התוצאות בוחרים "הדפסה / שמירה כ־PDF" ומשתמשים בדיאלוג ההדפסה של הדפדפן. גיליון ההדפסה מרחיב תוכן, משמר אזהרות, מונע פיצול כרטיסי שלבים ומפיק ניגודיות שחור־לבן. פקדי המסך והודעת העדכניות הקבועה אינם מודפסים.

## בדיקות ואיכות

```bash
npm test
npm run typecheck
npm run build
npm audit --omit=dev
```

הבדיקות מכסות שלמות תוכן, מנוע המלצות ופרטיות, זרימת Navigator, תוצאות והדפסה, ניווט ואינטראקציות במצגת, נגישות וחוזי מובייל. אין להריץ `npm audit fix --force`; שדרוג תלות צריך להיבדק מול המוצר והבדיקות.
